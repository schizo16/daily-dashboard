📂 Sidebar

  • ✦ Logo + tên app trên cùng
  • Mỗi item: icon + label
  • Active: background tint xanh
  • Hover: glass highlight
  • Weather widget ở bottom
  • Dễ dàng collapse thành icon
  • Border phải mảnh (0.5px)

🪟 Top Bar

  • Search bar (kiểu Spotlight)
  • Theme toggle (🌙→☀️)
  • Locale toggle (VI/EN)
  • AI Hub button
  • Glass effect nền
  • Sticky trên cùng

📄 Pages Content Pattern

HomeHero section (clock, greeting, weather) + search + notes grid + explore tiles
RadarTabs: GitHub / AI Models / HN / Tech News — mỗi tab là glass card với entries
MoviesPeriod picker pills + grid movie cards + modal detail
GamesTabs: Steam Deals / eSports / Gaming News + Wordle + Quiz cards
WatchlistList saved movies, swipe/xóa
MediaTabs: Music / Radio — player bottom bar persistent
ToolsGrid tool tiles → detail view per tool, back button
SettingsTheme, locale, API keys, about ✨ mới
