📐 Design — Phần 1: Tech Stack & Architecture

Apple Vibrancy + shadcn/ui + Framer Motion

🥞 Stack

BuildVite
UI FrameworkReact 18
StylingTailwind CSS v4
Componentsshadcn/ui (button, card, sidebar, tabs, dialog, input...)
AnimationFramer Motion (spring, stagger, layout animation, 3D transforms)
RouterReact Router v7
StateZustand (nhẹ, đơn giản, không boilerplate)
DeployCloudflare Pages / Vercel (giữ nguyên)
FontInter (gần nhất với SF Pro)

🏗️ Architecture

src/
├── App.tsx                   # Router + Layout
├── main.tsx                  # Entry point
├── components/
│   ├── ui/                   # shadcn/ui components
│   ├── layout/               # Sidebar, TopBar, Shell
│   └── shared/               # Reusable blocks (Entry, MovieCard, etc.)
├── pages/
│   ├── Home.tsx
│   ├── Radar.tsx
│   ├── Movies.tsx
│   ├── Games.tsx
│   ├── Watchlist.tsx
│   ├── Media.tsx             # Music + Radio tabs
│   ├── Tools.tsx
│   └── Settings.tsx          # ✨ MỚI
├── hooks/                    # useWeather, useGitHub, useTMDB...
├── stores/                   # Zustand stores (theme, locale, watchlist)
├── lib/                      # API clients, utils
├── i18n/                     # vi, en dictionaries
└── types/                    # TypeScript types
