✨ Design — Phần 4: Animation & 3D Strategy

Framer Motion + CSS + 3D transforms — đẹp, mượt, Apple-like

🎬 Page & Route Transitions

AnimatePresence → page enter:

opacity 0→1, y: 8→0, spring stiffness 200, damping 24

Page exit:

opacity 1→0, scale 1→0.98, duration 150ms

🔄 3D Interactive Effects

  • ✦ Card tilt — mouse parallax: perspective + rotateX/Y + translateZ

  • ✦ Hero 3D depth — clock floating, greeting layer separation
  • ✦ Stagger cards — each card enters with delay * index
  • ✦ Spring buttons — scale 1→0.97 on press

⚙️ Motion Config (Framer Motion)

// Apple spring - mượt, tự nhiên
const appleSpring = { type: "spring", stiffness: 200, damping: 24 }

// Page transition
const pageVariants = {
  enter: { opacity: 1, y: 0, transition: appleSpring },
  exit:  { opacity: 0, y: -8, transition: { duration: 0.15 } }
}

// 3D card tilt
const tiltStyle = (x, y) => ({
  transform: `perspective(600px)
    rotateX(${y * -3}deg)
    rotateY(${x * 3}deg)
    translateZ(8px)`
})

// Stagger children
const stagger = { animate: { transition: { staggerChildren: 0.05 } } }
