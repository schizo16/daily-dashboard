⚡ Bước 4: Build tool

React SPA — chọn stack build

A

Vite (Recommended)

Nhanh, đơn giản, đúng cho SPA — không cần SSR. Vite + React + Tailwind v4

Pros

  • Dev server siêu nhanh
  • Cấu hình tối thiểu
  • Deploy tĩnh được

Cons

  • Không SEO (không cần cho dashboard)
B

Next.js

Full framework — App Router, SSR, API routes. Hơi overkill cho dashboard cá nhân

Pros

  • SEO tốt
  • API routes tích hợp
  • Hệ sinh thái lớn

Cons

  • Nặng hơn cần thiết
  • Cấu hình phức tạp
  • Build lâu hơn

Chọn build tool bạn muốn 👇
